This challenge is an advanced and generalized version of the `Binary to Decimal` challenge.

Implement a type Convert<N, M, S> that converts a string S representing a number in base N to a string representing the same number in base M.

- N and M are integers between 2 and 16.
- The input S is a valid string representation of a number in base N.
- For bases greater than 10, use lowercase letters a to f (e.g., 10 becomes a in base 16).
