Merhaba Dünya!

Type Challenges'da, doğrulamayı gerçekleştirmek için tür sisteminin kendisini kullanıyoruz.

Bu challenge'da testlerin (tür denetimi hatası olmadan) başarılı olması için aşağıdaki kodu değiştirmeniz gerekiyor:

```ts
// string olması bekleniyor
type HelloWorld = any
```

```ts
// bunu çalışır hâle getirmelisiniz
type test = Expect<Equal<HelloWorld, string>>
```

Kod yazmaya başlamak için `Take the Challenge` düğmesine tıklayın! İyi çalışmalar!
